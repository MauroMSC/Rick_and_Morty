# Rick and Morty — Character Explorer

Aplicação web desenvolvida para explorar personagens do universo Rick and Morty, consumindo dados da [Rick and Morty API](https://rickandmortyapi.com/).

O projeto permite visualizar personagens, navegar entre páginas e consultar informações individuais em uma interface temática inspirada no universo da série.

##  Funcionalidades

- Listagem de personagens consumidos diretamente da API.
- Navegação entre páginas de personagens.
- Exibição de detalhes em uma janela modal.
- Informações sobre status, espécie, gênero e origem dos personagens.
- Tradução de algumas informações para português.
- Tratamento de erros e controle de requisições à API.

##  Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Rick and Morty API
- Font Awesome

##  Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

**Observação:** é necessário ter conexão com a internet para carregar os dados da API.

##  API utilizada

[Rick and Morty API](https://rickandmortyapi.com/)

API utilizada para obter os dados e as imagens dos personagens.
